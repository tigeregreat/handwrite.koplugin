# 手写笔记 handwrite.koplugin

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

给 KOReader 加一支「手指笔」：可以在正在看的书页上直接写字、圈画、算草稿，
也可以打开一块空白手写本随手涂写并存成 PNG。

针对 **Kindle Paperwhite 5（2021，1236×1648，无手写笔）** 调优，代码基于
KOReader **v2026.07.2** 的真实 API 编写并通过模拟环境测试。

> **English summary:** A KOReader plugin for handwriting directly on the page
> you are reading — with your finger, no stylus needed. Strokes are stored
> per-page in the book's `.sdr` sidecar and restored automatically on reopen.
> It ships with stroke beautification (quadratic B-spline + simulated pressure
> taper + per-pixel anti-aliasing), an e-ink-aware refresh scheduler
> (grayscale waveform, dirty-rect merging, throttling) and a floating toolbar
> that collapses into a translucent pill in the corner. Tuned for the
> **Kindle Paperwhite 5 (2021, 1236×1648)**, written against KOReader
> **v2026.07.2**. The full documentation below is in Chinese.

## 安装前必读

- 本仓库只是一个 KOReader 插件，**不包含也不提供任何越狱工具、Kindle 固件或
  破解文件**。越狱本身存在风险，因越狱、刷机、改动系统文件导致的设备问题
  与本项目无关。安装前请自行备份。
- 本仓库根目录就是插件目录，clone 或下载 zip 后，把整个 `handwrite.koplugin`
  文件夹拷进 Kindle 的 `koreader/plugins/` 即可（详见下方「安装」）。

## 功能

- **书页手写**：单指在页面上写，笔迹按页保存在该书的 `.sdr` 里，重开自动恢复
- **字迹美化**（默认开）：二次 B 样条把折线变曲线、速度模拟压感做出**起笔顿、行笔轻、
  收笔出锋**，边缘逐像素算灰度抗锯齿 —— 中文字明显好看一截，且没有马赛克颗粒；
  可一键关掉，也有弱/中/强三档笔锋可调
- **工具栏**（屏幕右侧，长按可拖走）：书写/停止、钢笔/橡皮、笔宽、**美化**、撤销、**刷新**、导出、隐藏
- **虚浮窗**（可选）：把工具栏收成右下角一枚**半透明小图标**，几乎不挡正文；要写字时点一下
  就唤出完整工具栏，**一段时间没动自动收回去**（默认 10 秒，可设 5/10/20/30/60 秒或**永不隐藏**）
- **橡皮**：点到笔迹即擦掉整笔；**撤销**：退回上一笔
- **双指仍然照常**：缩放、翻页、调菜单都不受影响
- **导出 PNG**：把当前一屏（书页＋笔迹）存到 `koreader/notes/handwrite/`
- **空白手写本**：多页草稿纸，**「新页」随时加页**，可整本存成 PNG，在文件管理器里查看
- **书写时的刷新画质**可调（默认「标准」= 灰阶波形）：笔迹写完立刻可见，不用再手动点刷新；
  另有「抗残影」「极速」两档（见下）
- **墨水屏优化**：书写时按「脏矩形合并 + 节流」的方式局部刷新（跟手）；整屏刷新（会黑闪）默认
  **只在停止书写或换页时**来一次，不会写两个字就闪；也可以改成「每 10/30/100 笔」或完全手动
  （工具栏「刷新」按钮随时清残影）
- **手势绑定**：可在「手势管理器」里绑定 开始/停止书写、钢笔切换、撤销、打开手写本
- **诊断信息**：菜单里可查看设备、屏幕、触摸接管、刷新能力等，便于排查

## 安装

1. Kindle PW5 已完成越狱（WinterBreak / LanguageBreak）并装好 KOReader。
   插件基于 **v2026.07.2** 编写并实测；更早的版本理论上可用但未做验证，
   遇到问题请先升级到最新的 KOReader
2. 把 `handwrite.koplugin` 整个文件夹拷进 Kindle 的 `koreader/plugins/`：
   - USB 连接后路径通常是 `Kindle:\koreader\plugins\`
   - 最终结构必须是：`koreader/plugins/handwrite.koplugin/main.lua`
3. 安全弹出，重启 KOReader（右上角菜单 → 退出，或重启设备）
4. 打开一本书 → 顶部菜单 → **更多工具 → 手写笔记**

若「更多工具」里没有，先到 菜单 → 设置（⚙）→ 插件管理 里确认插件已启用，
启用后需重启 KOReader。

## 使用

1. 打开书，进入 **更多工具 → 手写笔记 → 开始书写**（或点工具栏上的「书写」）
2. 单指在页面上写字；写错了点「撤销」，或用「橡皮」点掉某一笔
3. 双指手势照常：双指滑动翻页、双指缩放
4. 写完点工具栏「停止」，或「隐藏」工具栏（隐藏会自动停止）
5. 想把整屏存成图片：工具栏「导出」或菜单里的「导出本页为 PNG」
   → 文件在 `koreader/notes/handwrite/`，可在 KOReader 文件管理器里打开看

### 虚浮窗（嫌工具栏挡正文就用它）

工具栏常驻在屏幕上，竖屏看书时确实会压掉右边一窄条正文。打开 **手写笔记 → 虚浮窗**，
它就会收成**右下角一枚半透明小图标**：

```
┌────────────────────┐
│ 正文……              │
│ 正文……              │
│ 正文……        ╭──╮  │   ← 半透明小图标（约 56×40）
│ 正文……        │笔│  │      压在正文上也能看清底下的字
│ 正文……        ╰──╯  │
└────────────────────┘
```

- **点一下小图标** → 完整工具栏展开，正常书写 / 换工具 / 撤销
- **一段时间没动** → 自动收回去，变回小图标。这个时间在
  **虚浮窗 → 浮窗自动隐藏时间** 里改：5 / 10（默认）/ 20 / 30 / 60 秒，或者**永不隐藏**
- 计时从**最后一次点工具栏**算起；点任意一个按钮都会把表重新拨一遍
- 工具栏上的最后一个按键会变成「**收起**」，点它立刻收回去（不是把工具栏整个关掉）
- **收起状态下照样能写字**：单指点页面照常落笔，只有右下角小图标那一小块会把触摸让给菜单
- 写完的字盖到小图标上时，抬笔会自动把它重画一遍，不会缺一块

| 虚浮窗 | 工具栏上的「隐藏」键 | 效果 |
| --- | --- | --- |
| 关 | 隐藏 | 工具栏整个关掉（会同时停止书写） |
| 开 | 收起 | 暂时收成小图标，书写状态保留 |

不想用了再点一次菜单里的「虚浮窗」即可关掉，工具栏恢复常驻。

空白处涂写：**文件管理器 → 工具（左上角）→ 手写笔记 → 打开空白手写本**。

手写本按钮（上下两行）：

| 钢笔/橡皮 | 笔宽 | **美化** | 撤销 | 清空 | 刷新* | 存PNG |
| --- | --- | --- | --- | --- | --- | --- |
| ◀上页 | 第几页 | 下页▶ | **新页** | 存全部 | 关闭 | |

写满一页点「新页」继续写第二页，「◀上页 / 下页▶」来回翻，「存PNG」存当前页、
「存全部」一次存所有页。

「美化」按钮**点一下开关美化，长按切换笔锋强度**（弱 → 中 → 强）。
手写本的「刷新」按钮**点一下整屏刷新，长按循环切换书写画质档位**。

### 字迹美化

手指在墨水屏上写出来的线默认是「等宽 + 方块笔尖」，斜线和转弯全是硬锯齿，
小字尤其难看。美化是一条完整管线：

    原始触点 → 指数平滑去抖 → 二次 B 样条 → 沿弧长细分 → 速度算半径 → 逐像素算覆盖率

| 做法 | 效果 |
| --- | --- |
| **二次 B 样条** | 把折线变成 C1 连续的曲线，这才是「顺滑」的来源；只要多看一个点，滞后感比 Catmull-Rom 小得多 |
| **速度 → 笔宽**（模拟压感） | 走得快的地方细、慢的地方粗，一笔里自然出现起笔顿、行笔轻、收笔出锋 |
| **路径平滑** | 抹掉手指抖动和采样噪声 |
| **逐像素算覆盖率** | 每个像素按到中心线的**真实距离**算灰度，边缘一像素过渡带；没有查表量化，所以**没有马赛克** |

这套思路参考的是 **GoodNotes / Notability** 那类笔记软件公开的通用做法
（「输入平滑 → 样条插值 → 沿曲线撒笔尖印子」）—— 它们靠 GPU 一次性对整屏求距离，
这里按 Kindle 的 CPU 做成了「每帧只算最新一两段」的增量形式。

菜单 → 更多工具 → 手写笔记：

- **优化字迹（笔锋 + 抗锯齿）**：总开关，随时可以关掉退回等宽
- **笔锋强度**：弱 / 中（推荐）/ 强。越「强」快慢之间的粗细差越大，毛笔味越重；
  写小字或想要工整干净的字迹时建议用「弱」

关掉美化是最省 CPU 的兜底路径 —— 如果觉得写字发涩，先试试把笔锋调到「弱」。

### 书写时的刷新画质（为什么以前「要点一次刷新才看得见」）

墨水屏上「把像素写进显存」和「肉眼看见」是两件事，中间必须再向显示控制器发一次更新，
而**不同的波形（waveform）显示灰阶的能力完全不同**。KPW5 属于 MTK 平台的 Kindle：

| 波形 | KOReader 里的调用 | 这台机器上的表现 |
| --- | --- | --- |
| **UI / AUTO**（默认） | `Screen:refreshUI` | 驱动把灰度通道交给 GC16，**16 级灰阶正常显示**；不会被提升成整屏更新，也就不阻塞 |
| REAGL | `Screen:refreshPartial` | 画面最干净、自带残影清理，但每次都要等控制器完成 → **连着阻塞两次**，写快了跟不上手 |
| DU | `Screen:refreshFast` | 延迟最低，但驱动还会带 `FORCE_MONOCHROME` —— **任意灰度被压成 1bit 黑白** |

以前书写用的正是 DU，用来给正文做反显高亮很合适，可我们的美化笔迹恰恰是大量抗锯齿灰阶像素，
**会被整片压白** —— 这就是「写着看不见、点一下刷新才出来」的根因。
（顺带说明：早先那个「书写时快速刷新」开关关掉时会落到 REAGL，于是变成
「写一两个字就黑屏刷一次」，也是同一处波形选择不当。）

现在的做法是：默认用 **UI/AUTO 灰阶波形**，并且不逐点刷 ——
把两次刷新之间的所有小位移**并成一个外接矩形**，每 45ms 最多发一次更新。
**笔迹始终是按触点实时画进显存的**，被节流的只是「送上屏幕」这一步，所以最多延迟 45ms，
不会丢笔。三个时刻不看节流：落笔、抬笔、以及手指停住不动（由定时器补一次）。

菜单 → 更多工具 → 手写笔记 → **书写时的刷新画质**：

| 档位 | 波形 | 间隔 | 适合 |
| --- | --- | --- | --- |
| **标准（推荐）** | UI/AUTO | 45ms | 抗锯齿笔迹写完立刻可见，也不卡顿 |
| 抗残影（最干净，略慢） | REAGL | 200ms | 慢慢写、或特别在意残影；写快了会跟不上手 |
| 极速（黑白两色） | DU | 每帧 | 只要还想再省一点延迟。细笔画的灰边可能要等整屏刷新才显出来；
              为此落笔和抬笔那两下仍会自动用灰阶波形补一次，保证至少看得见 |

> 诊断信息里会显示当前实际落到哪个波形（例如「书写刷新：标准（推荐）（实际波形 refreshUI）」），
> 排查时先核对这一行。

### 整屏刷新（黑闪）怎么控制

菜单 → 更多工具 → 手写笔记 → **整屏刷新时机**：

| 选项 | 行为 |
| --- | --- |
| 停止书写/换页时（默认） | 写字过程完全不打断，只在停手或换页时刷一次 |
| 不自动（只手动刷新） | 完全不自动黑闪，需要时点工具栏「刷新」或菜单「立即整屏刷新」 |
| 每 10 / 30 / 100 笔 | 写满相应笔数刷一次（笔 = 一划，一个字通常 1–3 笔） |

残影只是墨水屏的显示残留，不影响笔迹数据，随时手动刷一次就干净了。

## 已知限制

- 笔迹按**屏幕坐标**保存。改了字体大小、行距、页边距、横竖屏或换了设备后，
  旧笔迹会对不上内容（插件会在布局变化时给出提示）。PDF 在非缩放状态下最稳。
- PW5 没有压感和手写笔， Palm rejection（防误触）没有，写字时手掌别贴屏幕。
- 快速刷新会有轻微残影，属于墨水屏特性；把刷新画质调到「抗残影」可换取更干净的笔迹。
- 手写本的笔迹只在内存里，必须显式「存PNG」才会落盘，关闭前会提示。
- 美化的抗锯齿需要**灰阶屏**（4/8bpp）。极少数 1bit 屏上看不到灰度过渡，
  但笔画形状（笔锋、圆笔尖）仍然有效。
- 美化只改「怎么画」，不改存的数据：开关随时切换，老笔迹也一样能美化。
- 虚浮窗的小图标固定在右下角，不能拖动（拖动的是展开后的工具栏）。半透明是**混合**出来的，
  不是「白底加透明度」：图标压在很密的黑字上时仍会看得见一点底下的笔画，这是墨水屏上
  20 级灰阶的限制，属正常现象。
- 虚浮窗折叠时，UIManager 会连它下面的书页一起重绘，保证半透明的底图是最新的。
  每次刷新浮窗的代价因此比普通控件略高（约多画一块书页），只在**展开/收起/压到图标**时发生。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 菜单里没有「手写笔记」 | 设置 → 插件管理里启用后重启 KOReader；确认目录名是 `handwrite.koplugin` |
| 提示「无法开启书写：触摸接管失败」 | 菜单 → 手写笔记 → 诊断信息，看「触摸接管」是否为不可用（极老或非标准设备） |
| 写字时页面乱翻 | 确认是用单指起笔；双指才会被当成翻页/缩放 |
| 点不动菜单 | 书写中若菜单打不开，点工具栏「停止」再进菜单 |
| **写一笔要点一下「刷新」才看得见** | 查看诊断信息里的波形是不是 `refreshUI`；若停在 `refreshFast`（DU 会把灰阶压白），到菜单把「书写时的刷新画质」改回**标准** |
| 写字总体偏慢 / 不跟手 | 刷新画质调到**极速**；或把「笔锋强度」调成「弱」，乃至关掉「优化字迹」 |
| 残影多 | 点工具栏「刷新」，或把「整屏刷新时机」改成每 10 笔，或把刷新画质调到「抗残影」 |
| **工具栏挡住正文** | 菜单打开「虚浮窗」，它会收成右下角小图标；也可以长按工具栏把它拖到不挡字的位置 |
| 打开虚浮窗后工具栏不见了 | 看屏幕**右下角**那枚半透明小图标，点一下就回来；嫌太低可以把「浮窗自动隐藏时间」改成「永不隐藏」 |
| 点小图标没反应 | 确认点的是右下角那一小块（它只有约 56×40）；书写中被别的东西挡住时，先点页面退出书写再试 |
| 小图标自己被笔迹盖住了 | 抬笔时插件会自动重画它；若仍有残留，点一下工具栏「刷新」 |
| 虚浮窗展开后自己收起来了 | 这是设计行为；到「浮窗自动隐藏时间」把秒数调大，或选「永不隐藏」 |
| 写字发涩 / 有延迟 | 菜单里关掉「优化字迹」，或把「笔锋强度」调成「弱」（默认档本来只有 ≈0.25 个采样点的滞后） |
| 笔画的边缘看着有台阶 / 颗粒感 | 说明正在用旧的量化渲染：确认版本 ≥ 1.3.0，且开着「优化字迹」 |
| 写着写着前面的线变淡或消失 | 1.3.0 起加了**半径绝对下限**，最细也有一颗纯黑像素；另外手写本改成了统一以画布为准，每次局部刷新都会把这一块同步回显存 |
| 笔迹不显示 | 确认没关「自动清理残影」且当前页确实有笔迹（诊断信息里可看笔数） |
| 导出后找不到图 | 在 `koreader/notes/handwrite/` 下，可用 KOReader 文件管理器打开该目录查看 |

## 卸载

删除 `koreader/plugins/handwrite.koplugin` 目录并重启 KOReader。
书里的笔迹存在各书的 `.sdr/metadata.*.lua` 中（键名 `handwrite_ink`），
用菜单里的「清除整本书笔迹」可逐本清掉。

## 性能

PW5 的 CPU 很弱，美化是照着这个前提设计的：

- **算法是因果（只依赖过去）的**。书写时每来一个触点只画最新的一两段胶囊，
  开销只跟这两段的长度有关，**不随笔画写多长而累积**。
  实测第 120 段的绘制开销与第 1 段同量级（都是几十到一百多次像素调用）。
- **抬笔不需要重画整条笔画**。因为宽度只由历史速度决定，「边写边画」和
  「换页重绘」的结果**逐像素相同**（测试里有逐点 + 逐像素比对的断言），不会在抬手时跳变。
- **半径不落盘**。sidecar 里还是原来的 `{n, w, s, x, y...}`，重绘时重算一遍即可，
  老笔迹照样能美化。
- **热路径零分配**：覆盖率量化成 64 档并预生成 `Color8A` 对象。
- **手写本不再两块画布各画一遍**：只画自己的画布，局部刷新时同步进 framebuffer，
  每帧的绘制开销直接减半，也杜绝了「画布和显存不一致」
- **EPDC 更新不逐点发**：写字时把新墨迹先并成一个外接矩形，每 45ms 最多向屏幕发一次更新
  （见「书写时的刷新画质」一节）。实测 400 个采样点只发出 9 次更新，
  而单次 UI/AUTO 更新在这台机器上是非阻塞的，所以既跟手也不占用 CPU
- 兜底：菜单里关掉「优化字迹」就退回原来的等宽方块路径。

代价主要在**换页/翻页重绘**时（要把整页笔画重算重画）：路径总长每一像素
约为 15 次像素调用 —— 换算下来，写一整页中文大约十几万次调用，
落一次几十毫秒的量级：换页那一瞬会有停顿，属于正常范围。


## 实现说明

- `hw_capture.lua` 包一层 `GestureDetector:feedEvent(slots)` 取原始触点（KOReader 无公开 API，
  这是社区通用做法，只在书写时安装、退出生效即卸载）；含横竖屏坐标换算
- `hw_ink.lua` 美化算法本体：指数平滑 → 二次 B 样条 → 沿弧长细分 → 速度/压感算半径
  → 输出一串「锥形胶囊」`{n, x0,y0,r0,x1,y1,r1, ...}`。纯计算、因果流式（不依赖未来点），
  可离线单测；宽度不落盘，重算即可
- `hw_render.lua` 光栅化：把胶囊逐像素算成灰度（距离 → 覆盖率），另有等宽兜底路径。
  书写热路径只画新增的一两段；每个入口先把包围盒夹进画布（blitbuffer 的
  `setPixelBlend` 不做越界检查）
- `hw_refresh.lua` 书写刷新调度器：按档位选波形（灰阶 / REAGL / DU）、合并脏矩形、
  节流（45ms）、挂 UIManager 定时器补刷停手时的最后一截，并负责把矩形夹进屏幕
- `hw_store.lua` 按页存笔画，纯数字结构可直接进 sidecar
- `hw_toolbar.lua` 侧边工具栏，兼虚浮窗：折叠态画半透明小胶囊（`blendPill` 逐行混合，
  正屏走 `lightenRect/darkenRect` 的 C 快路径，旋转时退回 `paintRect + setPixelBlend`），
  并在 `widget.alpha` 上挂透明系数让 UIManager 把下层一起标脏
- `hw_notebook.lua` 空白手写本
- `main.lua` 生命周期、菜单、Dispatcher 动作、导出与诊断；
  虚浮窗的展开 / 收起 / 自动收起倒计时（`pokeFloatBar` / `collapseBar` / `expandBar`）也在这里
